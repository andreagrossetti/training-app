Allenamento

A personal Android app for bodyweight workouts, GPS runs and HRV readings. It isn't publicly distributed: only its author uses it. Source code: github.com/andreagrossetti/training-app.

Privacy policy

Last updated: 25 September 2026.

All of the app's data (programs, workout diary, run routes, HRV readings, settings) is stored on the phone. The app has no server, uses no ads or analytics, and doesn't sell or share data with anyone.

Google Drive

If the user turns on the Drive backup, the app uploads a backup file every week to an "Allenamento" folder in their Google Drive. It only uses the drive.file permission: it can see and change only the files it created, not the rest of the Drive. The files stay in the user's account and can be deleted at any time; access can be revoked at myaccount.google.com/permissions.

Health Connect

If the user turns it on, the app writes its workouts, runs (with distance and route), HRV and resting heart rate to Health Connect, so they can be seen in other apps such as Samsung Health. The app doesn't read any data from Health Connect.
